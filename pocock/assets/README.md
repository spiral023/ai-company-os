# Portrait-Icon

`portrait-source.png` ist das mit dem eingebauten Imagegen-Werkzeug am 29.10.2026 erzeugte Original. Die zwei vom Nutzer beigefügten Fotos dienen als Motiv- und Ähnlichkeitsreferenz für die Illustration von Matt Pocock. Die Fotos selbst werden nicht im Repository veröffentlicht. Das Icon kennzeichnet diesen privaten Kurszugang; es ist kein offizielles Logo des Kursautors.

Der vollständige Generierungs-Prompt steht in [imagegen-prompt.txt](imagegen-prompt.txt). `python pocock/build_icons.py` erzeugt mit Pillow ausschließlich technische Größenvarianten und das ICO-Format, ohne das Motiv zu verändern. Die auslieferbaren Dateien liegen unter `pocock/public/`.

Metadaten im Blick

Betroffene Dateien anzeigen
So wird gezählt
  • Rohdateien: direkte Markdown-Notizen in den Typordnern. Medien, Unterarchive und READMEs im Root werden nicht mitgezählt.
  • Eindeutige Rohquellen: zusammengefasste Post-/Video-IDs beziehungsweise normalisierte URLs. Ein Thread bleibt eine archivierte Quelle. Fehlende URLs bleiben dateibasiert getrennt.
  • Source-Notizen: redaktionelle Aufarbeitungen und importierte Wissensnotizen. Sie sind eine eigene Zählmenge und werden nicht zum Roharchiv addiert.
  • Snapshots: unveränderliche Messungen. Änderungen an Zählregeln oder Autoren-Aliasen beginnen eine neue vergleichbare Reihe.
  • Geltungsbereich: Importarchive unter external_knowledge und Analyse-Repos unter external_repos werden separat gehalten.
Diese Metadatenprüfung ersetzt den vollständigen Knowledge-Validator nicht.

# Sichtbare Änderungen mit annotierten PR-Screenshots erklären

Cole Bemis empfiehlt, den Coding Agent annotierte Screenshots an einen Pull Request anhängen zu lassen. Das Bild zeigt markierte Bereiche einer Sidebar und einen Agent-Abschlussbericht.

## Kernaussagen

- Screenshots mit Markierungen können dem Reviewer zeigen, welche sichtbaren Bereiche betroffen sind → [[Visuelle-Abnahme-mit-Live-Lokal-Vergleich]].
- Der Bildausschnitt stellt Anpassungsmodus und normale Sidebar gegenüber; die Annotationen erklären Sichtbarkeit und Reihenfolge.
- Beschriebene Tests und Browserprüfung sind Aussagen im Agent-Bericht, keine hier unabhängig ausgeführten Checks.

## Einordnung

Ein annotiertes Bild ist ein Review-Artefakt. Es beweist weder vollständige Interaktionsprüfung noch eine bestandene Produktionsabnahme. Die Quelle ergänzt die Nachvollziehbarkeit visueller Ergebnisse; sie beschreibt selbst keinen vollständigen Live/Lokal-Vergleich.

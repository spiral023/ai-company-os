# Docker Sandboxes steht in den Claude-Code-Docs als empfohlene Isolation

Docker meldet, dass Docker Sandboxes in der offiziellen Claude-Code-Dokumentation als empfohlener Weg auftauchen, Claude Code mit MicroVM-Isolation zu betreiben. Es ist eine Herstellerankündigung ohne Detailprüfung.

## Kernaussagen
- Jede Sandbox hat laut Docker einen eigenen Kernel und einen eigenen Docker-Daemon. → [[Sandbox-Komposition-aus-OS-Primitiven]]
- Docker Desktop wird dafür nicht benötigt.
- Die Nennung in den Docs ist ein Signal, dass MicroVM-Isolation neben Bordmitteln als Standardpfad gilt.

## Einordnung
Die Docs-Aufnahme habe ich nicht am Original geprüft. Gegenüber Sandbox-Bordmitteln bietet MicroVM härtere Trennung, kostet aber Start- und Betriebsaufwand. Details zur Konfiguration fehlen.

# Dokumentationsdrift benennen, statt Code blind an alte Regeln anzupassen

Vox empfiehlt, bei Widersprüchen vorhandene Codekonventionen zu berücksichtigen und Abweichungen zur Dokumentation ausdrücklich zu melden. Seine Versuchszahlen bleiben ohne benannte Primärstudie unbelegte Sekundärangaben.

## Kernaussagen

- Veraltete Agent-Dateien können eine falsche Umsetzung vorgeben; Code und Dokumentation deshalb als getrennte Belege abgleichen → [[AGENTS-md-Onboarding-Design]].
- Der vorgeschlagene Prompt verbindet Orientierung am bestehenden Code mit einem abschließenden Widerspruchsbericht → [[AGENTS-md-Onboarding-Design]].
- Genannt werden `79/80` problematische Claude-Code-Läufe, Codeänderungen in `1/4` der Codex-Läufe und ein Effekt von `4 %` auf `91 %`. Modellstände, Aufgaben, Nenner und Messprotokoll fehlen → [[Testharness-als-staerkster-Hebel]].

## Einordnung

Die Zahlen erlauben weder ein allgemeines Produkturteil noch einen geprüften Effekt dieser Regel. Vorhandener Code kann selbst fehlerhaft sein: Codekonventionen ersetzen keine ausdrücklichen Sicherheits- oder Verhaltensanforderungen und dürfen berechtigte Korrekturen nicht verhindern.

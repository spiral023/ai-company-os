# Opus 5.5 führt den Coding Agent Index, aber mit den höchsten Kosten pro Task

Artificial Analysis (Drittanbieter) misst Coding Agents als Kombination aus Harness und Modell im Coding Agent Index v1.5: DeepSWE v1.1, Terminal-Bench 4.0 und SWE-Atlas-QnA, gleich gewichtet. Claude Code mit Opus 5.5 (max) erreicht 66 Punkte, der höchste gemessene Wert. Alle Kosten hier beziehen sich auf den Coding Agent Index (pay-per-token API).

## Messwerte (Stand 2026-09-24)

- Claude Code Opus 5.5 (max): 66; Opus 5 (max): 60; Claude Fable 5.1 (max, Fallback): 62 (laut Chart gleichauf mit Codex GPT-6 Astra und Devin Fusion Fable 5.1 bei 62); Codex GPT-6 Sol (max): 57; Codex GPT-6 Luna (max): 41.
- Opus 5.5 gegenüber Opus 5: Terminal-Bench 4.0 63,1 % (54,5 %), DeepSWE v1.1 68,4 % (62,5 %), SWE-Atlas-QnA 66,4 % (62,1 %).
- Cost per Task Opus 5.5: `$13.04`, +21 % gegenüber Opus 5 (`$10.79`). Verbrauch ca. 15,6 Mio. Token pro Task gegenüber 11,4 Mio., davon ca. 2,4-mal so viele Output-Token.
- Preis Opus 5.5: `$4`/`$20` pro 1M Input/Output (Opus 5: `$5`/`$25`), Cache Reads `$0.20` (vorher `$0.50`).
- Kein günstigeres Modell im Vergleich erreicht den Score; Opus 5.5 verschiebt die Pareto-Front am teuren Ende nach oben.

## Einordnung

Die Preissenkung wird durch deutlich höheren Tokenverbrauch überkompensiert. Der Score gilt für die Kombination mit Claude Code im max-Effort, nicht für das Modell allein. Für Codex GPT-6 Sol (Score 57, `$2.99` pro Task) liefert die Pareto-Front das bessere Preis-Leistungs-Verhältnis.

# Scrollanimationen benennen und abnehmen

Vox kuratiert Begriffe und einen Prompt für `Opus 5.5`. Übertragbar: präzise Bewegungsbeschreibungen, begründete Auswahl und Abnahme.

## Auslöser, Bindung und Verhalten unterscheiden

| Begriff | Gemeintes Verhalten |
| --- | --- |
| Scroll-triggered | Sichtbarkeit löst eine anschließend zeitgesteuerte Animation aus; einmaliges Abspielen ist eine mögliche Konfiguration. |
| Scroll-linked | Fortschritt folgt der Scrollposition, beim Zurückscrollen rückwärts. |
| Parallax | Ebenen bewegen sich unterschiedlich schnell. |
| Sticky | Ein Element bleibt innerhalb seines Containers an einer Position haften. |
| Pin | Ein Abschnitt bleibt während einer Scrollsequenz stehen; sein Inhalt verändert sich. |
| Scroll Snap | Ein Scrollcontainer richtet sich an definierten Rastpunkten aus. |
| Horizontal Scroll | Hier konkret: vertikales Scrollen steuert horizontale Bewegung; keine allgemeine Definition. |
| Stagger | Elemente beginnen zeitlich versetzt. |
| Text Reveal | Text wird schrittweise hervorgehoben. |
| Progress Bar | Eine Anzeige visualisiert Lesefortschritt. |

## Auswahl vor Umsetzung, Prüfung im Browser

Erst Seiten prüfen, Effekte samt Zweck vorschlagen und ungeeignete Stellen auslassen. Bei Unsicherheit hilft eine Vorschau mit echten Inhalten; Umsetzung erst nach Auswahl. Vorherige Screenshots bilden den Vergleichszustand.

Animierte Eigenschaften auf `transform` und `opacity` begrenzen. Vorhandene Bibliotheken, lokale Snap-Container und mobile Alternativen begrenzen Eingriffe. `prefers-reduced-motion` und fehlende Browserunterstützung müssen sämtliche Inhalte zugänglich halten. Desktop und Mobile vollständig durchscrollen: Überdeckung und horizontalen Überlauf prüfen.

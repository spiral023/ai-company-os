# Komponentenbibliothek als Design-Reference-Skill und UX-Audit per Agent

Vox zeigt, wie Du eine bevorzugte Komponentenbibliothek (Web-Katalog, Open-Source-Repo oder lokales Verzeichnis) als Skill verpackst, den Codex beim Seitenbau nutzt. Der Skill muss drei Dinge festlegen: wo gesucht wird, was ausgewählt wird und wie es ins Projekt übernommen wird. Ergänzt wird ein UX-Audit-Skill, der als Erstnutzer Flows real durchklickt. Es ist eine Praxisanleitung mit Prompt-Vorlagen, ohne Messung.

## Kernaussagen
- Referenzquelle, Auswahlkriterien und Prüfschritt (Browser, Desktop und Mobile) gehören in den Skill, statt bei jedem Auftrag Links einzufügen → [[Erweiterungs-Ebenen-Zuordnung]]
- Der Skill soll ehrlich melden, wenn Zugriff auf Quellen fehlt, statt Abruf vorzutäuschen.
- Ein Audit-Prompt mit konkreter Nutzeraufgabe (Plan wählen bis Registrierung) liefert Reproduktionsschritte, Screenshots und Fixes → [[Skill-Call-Hierarchie]]

## Einordnung
Nützliches Vorlagenmuster, aber selbstberichtet: Es gibt keine Qualitätsprüfung der Ergebnisse. Die Bibliothek nennt ein kostenloses Nutzungslimit, und das UX-Audit-Original ist für Claude Code gebaut und muss für Codex angepasst werden.

# Claude Code `/checkup` räumt Konfiguration und Kontext auf

Boris Cherny kündigt den Befehl `/checkup` für Claude Code an (Stand 2026-07-08). Das ist eine Primärquelle des Herstellers, aber nur eine Funktionsliste: Wirkung und Einsparung werden nicht gemessen.

## Kernaussagen

- `/checkup` räumt ungenutzte Skills, MCPs und Plugins weg, dedupliziert lokale gegen eingecheckte `CLAUDE.md` und zerlegt eine Root-`CLAUDE.md` in verschachtelte `CLAUDE.md`-Dateien plus Skills → [[Kontext-Hygiene-Entscheidungsbaum]]
- Weitere Punkte: langsame Hooks abschalten, Version aktualisieren, Auto Mode aktivieren, oft abgelehnte Read-only-Befehle vorab freigeben.
- Der Befehl fragt vor jeder Änderung nach.

## Einordnung

Hersteller-seitige Bestätigung, dass Kontext-Hygiene und schlanke `CLAUDE.md` Standardprobleme sind. Der Punkt „Auto Mode standardmäßig“ ist eine Sicherheitsentscheidung, die Du bewusst treffen solltest, nicht per Vorschlag durchwinken.

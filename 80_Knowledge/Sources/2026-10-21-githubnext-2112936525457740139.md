# PDD Kit verbindet Spezifikationsreview mit formaler Verifikation

GitHub Next kündigt am 21.10.2026 das `Proof Driven Development Kit` von Microsoft Research an.

## Kernaussagen

- `PDD Kit` soll aus Diskussion und Plan eine formale Spezifikation in `Verus` für `Rust` ableiten; Menschen bestätigen die Spezifikation vor der Verifikation.
- Der `Verus`-Verifier soll beweisen, dass der erzeugte Code die spezifizierten Eigenschaften für alle erfassten Eingaben erfüllt.
- Wo kein Beweis möglich ist, sieht der angekündigte Ablauf Tests und Computer-Use-Agents vor. Diese liefern empirische Nachweise.
- Die Integration mit `Chopin` unterstützt gemeinsames Planen; als Ziel nennt GitHub eine Softwarefabrik mit Spezifikationsreview.

## Einordnung

Dies ist eine Herstellerankündigung; die [lokale Videodemo](../../00_Inbox/Quellen/X/medien/2026-10-21-githubnext-2112936525457740139/01-video.mp4) wurde nicht gesichtet. Ein Beweis gilt innerhalb der formalisierten Eigenschaften und Annahmen: Eine unvollständige oder falsche Spezifikation garantiert keine vollständige Anwendungssicherheit. Aus dem Post folgt keine unabhängige Prüfung der Implementierung oder des gesamten Login-Flows.

# Codex über Nacht: Worktrees, Heartbeats und Fix-Loop

Emanuele Di Pietro beschreibt einen selbstberichteten Nachtlauf mit Codex: Threads in Worktrees, Heartbeats zum Einchecken, Review von PRs und Issues sowie ein Codex-Bot auf GitHub, der Issues in einer Schleife abarbeitet. Das Ergebnis („merge-ready PRs“) ist nur behauptet, ohne Zahlen oder Fehlerquote.

## Kernaussagen

- Jede parallele Aufgabe läuft in einem eigenen Worktree → [[Kontrollierte-Agent-Parallelisierung]]
- Ein Modell (GPT-5.5 Pro) schärft vorab den Prompt; der Prompt wird zum ganzen Workflow → [[Ralph-Loop-Frischer-Kontext-pro-Iteration]]

## Einordnung

Bekannte Loop-Arbeitsweise unter neuem Namen. Kosten, Review-Aufwand am Morgen und Risiko unbeaufsichtigter Läufe nennt die Quelle nicht; ohne Review-Gate bleibt „merge-ready“ eine Behauptung.

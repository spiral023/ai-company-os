# UX, DX und Agent Experience gemeinsam als Ziele benennen

Wayne Sutton empfiehlt einen Prompt, der Entscheidungen zugleich an User Experience, Developer Experience und Agent Experience ausrichtet. AX bezeichnet hier Agent Experience.

## Einordnung

Der Prompt benennt gemeinsame Ziele, aber keine Gewichtung, Konfliktregeln oder Bewertungsmethode. „Ohne etwas kaputtzumachen“ formuliert einen Wunsch; Regressionen brauchen eigene Nachweise. Wayne nennt `Astra`, `Fable` und `Grok`, ohne Vergleich oder Wirksamkeitsbeleg. Die archivierte Verweiskette führt über Joe Devon zum bereits verarbeiteten Artikel von `@pvncher`.

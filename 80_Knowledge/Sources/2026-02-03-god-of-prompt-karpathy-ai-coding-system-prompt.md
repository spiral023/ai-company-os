# System Prompt gegen typische Agent-Fehler nach Karpathy

Deutsche Aufarbeitung (Sekundärquelle) eines Tweets, der Karpathys Kritik an Coding Agents in einen langen System Prompt für `CLAUDE.md` gießt. Der Prompt ist eine Fehlerliste als Anweisung, nicht getestet; ob er wirkt, belegt die Quelle nicht.

## Kernaussagen
- Annahmen vor dem Implementieren offenlegen, bei Widersprüchen anhalten und fragen, Widerspruch statt Gefälligkeit → [[Spec-Grilling]]
- Erfolgskriterien statt Schrittbefehle, Test zuerst als Schleifenbedingung → [[TDD-als-Verifikationshebel]]
- Eng scopen, Einfachheit erzwingen, Änderungen mit „nicht angefasst“-Liste melden.

## Einordnung
Bekannte Prinzipien, gebündelt. Ein so langer Prompt konkurriert im Context und wird laut anderen Quellen weich befolgt.

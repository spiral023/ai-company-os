# Artificial Analysis: GPT-5.6 Sol, Terra, Luna im Index-Vergleich mit Claude Fable 5

Artificial Analysis (AA) misst die drei GPT-5.6-Modelle im eigenen Intelligence Index v4.1 und im neuen Coding Agent Index. AA nennt selbst, OpenAI bei der Pre-Release-Evaluation unterstützt zu haben. Die Zahlen stammen von einem Drittanbieter, der Coding Agent Index misst Modell plus herstellereigene Harness (Codex, Claude Code, Grok Build), nicht Modelle allein.

## Intelligence Index (Stand 2026-07-09, jeweils `max` bzw. wie angegeben)
Laut Chart: Claude Fable 5 (with fallback) 60, GPT-5.6 Sol 59, Claude Opus 4.8 56, GPT-5.6 Terra 55, GPT-5.5 (xhigh) 55, Grok 4.5 (high) 54, GPT-5.6 Luna 51. Der Index bündelt neun Evals, darunter GDPval-AA v2, Terminal-Bench v2.1, HLE und GPQA Diamond. Cost per Task im Index: Sol `$1.04`, Terra `$0.55`, Luna `$0.21`; AA beziffert Fable 5 auf etwa das Dreifache von Sol (ohne genannten Absolutwert).

## Coding Agent Index
Composite pass@1 über DeepSWE, Terminal-Bench v2 und SWE-Atlas-QnA. Chart: Sol in Codex 80, Terra 77, Fable 5 in Claude Code 77, GPT-5.5 76, Grok 4.5 in Grok Build 76, Luna 75, Opus 4.8 in Claude Code 73. AA gibt Sol etwa 40 % (gegenüber Fable 5) und etwa 10 % (gegenüber Opus 4.8) niedrigere Kosten pro Task an.

## Preise und Token-Effizienz
Sol/Terra/Luna kosten `$5/$30`, `$2.5/$15`, `$1/$6` je Million Input-/Output-Tokens; Cache-Reads 90 % Rabatt, erstmals Cache-Writes bei OpenAI mit 1,25-fachem Input-Preis. Sol (max) braucht etwa 15k Output-Tokens je Index-Task, GPT-5.5 16k.

## AA-Briefcase
Fable 5 führt (Rubric Score 56 % gegenüber 42 % bei Sol; Analytical Quality Elo 1764 gegenüber 1592), Sol hat die höchste Presentation Elo.

## Einordnung
Belastbarer als Herstellerangaben, weil Drittmessung, aber mit Vorab-Zugang durch OpenAI und Harness-Bindung im Coding Index. Die Kostenführerschaft gilt am Pareto-Rand für `max`; die Qualitätsführerschaft bei Wissensarbeit bleibt bei Fable 5. Terra liegt laut AA stets hinter Luna oder Sol auf der Pareto-Front.

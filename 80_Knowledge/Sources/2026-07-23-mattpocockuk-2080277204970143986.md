# Agent-Änderungen per CLI mit einer menschlichen Live-Ansicht verbinden

Matt Pocock beschreibt für Arbeiten außerhalb des Codings eine wiederkehrende Aufteilung: Ein Agent bearbeitet Inhalte über eine CLI; ein Mensch sieht das Ergebnis in einer speziell dafür gebauten, automatisch aktualisierten Oberfläche. Als Einsatz nennt er Kurserstellung.

## Bearbeitung und Ansicht getrennt gestalten

Die CLI stellt dem Agenten die Bearbeitungsmöglichkeiten bereit. Die Ansichtsoberfläche zeigt die Änderungen in einer für Menschen passenden Form. Im Vorschlag müssen Agent und Mensch deshalb nicht dieselbe Bedienoberfläche verwenden. Der Post beschreibt das Muster, veröffentlicht aber weder die CLI noch die Oberfläche oder einen gemessenen Vergleich.

## Einordnung

Übertragbar ist die Kombination eines programmatisch bedienbaren Bearbeitungswegs mit einer anschaulichen Rückmeldung. Dass sich die Ansicht automatisch aktualisiert, ersetzt keine fachliche Abnahme oder Kontrolle der vom Agenten vorgenommenen Änderungen. Die Aussage über umfassende Agent-Kontrolle ist keine Empfehlung, unnötige Berechtigungen zu vergeben. Aufwand für CLI, Ansicht und deren konsistenten Zustand bleibt im Beitrag unbeziffert.

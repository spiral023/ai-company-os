# Tane: Der SDLC kollabiert zum Loop aus Intent, Build und Observe

Deutsche Aufarbeitung (vibedeck, Sekundärquelle) eines Meinungsartikels. These: Mit Coding-Agents verschmelzen die SDLC-Phasen zu einem engen Loop; übrig bleiben Kontext und Observability. Reine Position, keine Daten.

## Kernaussagen
- Requirements und Design werden fließend; Code Review gilt als Flaschenhals, den ein zweiter Adversarial Agent ersetzen soll → [[Plan-first-mit-getrenntem-Review]]
- Deployment und Release werden entkoppelt (Feature Flags, Canary)
- Monitoring wird Sicherheitsnetz; Telemetrie soll als Kontext an den Agent zurückfließen (Closed Loop)
- Kontextqualität bestimmt Ergebnisqualität → [[Intent-Engineering-als-dritte-Schicht]]

## Einordnung
Spekulative These; der Ersatz menschlichen Reviews durch Agent-Review ist nicht belegt und widerspricht der Praxis mit Review-Gates. Der Closed Loop ist plausibel, wird aber nicht gezeigt.

# Pareto-Front Intelligence vs. Kosten verschiebt sich um elf Punkte

Artificial Analysis (Drittanbieter) meldet, dass MiMo-V2.6-Pro, Claude Opus 5.5, GPT-6 Luna und GPT-6 Sol die Pareto-Front von Intelligence Index gegen Cost per Task in einer Woche um elf neue Punkte erweitert haben. Die Punkte entstehen durch verschiedene Reasoning-Efforts: fünf von GPT-6 Luna, vier von Opus 5.5, je einer von MiMo-V2.6-Pro und GPT-6 Sol. Alle Werte hier gelten für den Intelligence Index (nicht Coding Agent Index). Als Anhang liegt nur ein animiertes Video vor, aus dem Text ergeben sich die Werte.

## Eckpunkte auf der Front (Stand 2026-09-23)

- GPT-6 Luna (max): 37 Punkte bei `$0.068` pro Task.
- MiMo-V2.6-Pro: 46 Punkte bei `$0.13`.
- GPT-6 Sol (max): 48 Punkte bei `$1.06`.
- Claude Opus 5.5 (max mit Fallback): 58 Punkte bei `$5.98`, höchster gemessener Score.

## Einordnung

Kosten pro Task sind gewichtete Durchschnitte über die Intelligence-Index-Aufgaben, kein Wert für reale Coding-Sitzungen (dort ca. `$13.04` für Opus 5.5, siehe Coding Agent Index). Die Front ist relativ zum jeweils gemessenen Modellset.

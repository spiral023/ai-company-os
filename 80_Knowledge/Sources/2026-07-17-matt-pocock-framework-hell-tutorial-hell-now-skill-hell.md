# „Skill Hell“ durch ungezielte Prozesssammlung

Pocock kritisiert im automatisch erzeugten Transkript das ungeprüfte Zusammenladen mehrerer Skill- und Entwicklungsframeworks. Der Kurzbeitrag liefert eine Position zur Prozesssteuerung, keine gemessene Leistungsanalyse.

## Kernaussagen

- Mehrere ungesichtete Frameworks und Skills im selben Kontext können das Modell überlasten und einen unverständlichen Prozess erzeugen.
- Skills sollen bewusst ausgewählte, wiederholbare Arbeitsabläufe des Nutzers abbilden; die Sammlung allein schafft keinen Nutzen.
- Der Nutzer behält die Auswahl der Prozessschritte und Schleifen. Das schließt zeitweise unbeaufsichtigte Delegation ausdrücklich ein.

## Einordnung

Der zusätzliche Gedanke gegenüber reiner Kontextbereinigung ist die Zuständigkeit: Prozessauswahl bleibt eine menschliche Entscheidung, auch bei delegierter Ausführung. Der Beitrag nennt weder eine sichere Skill-Anzahl noch einen Benchmark für Kontextüberlastung.

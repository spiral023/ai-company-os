# Eine Kampagne als begrenzte Karte offener Entscheidungen führen

Shann Holmberg überträgt Wayfinder auf Kampagnenplanung: Ein übergeordnetes Issue enthält die Karte, einzelne Tickets klären jeweils eine Entscheidung. Die Quelle berichtet Anwendungserfahrung ohne messbaren Vergleich.

## Kernaussagen

- Grilling, Prototypen, Recherche und menschliche Aufgaben passend zur offenen Entscheidung wählen → [[Projektkarte-als-Status-und-Entscheidungsartefakt]]
- Nur unblockierte Tickets bearbeiten; Angebot und Zielgruppe können spätere Entscheidungen sperren → [[Blockierende-Task-Abhaengigkeiten]]
- Eine Karte auf eine Kampagne begrenzen und billige Entwürfe als Entscheidungshilfe verwenden → [[Variantenvergleich-vor-Produktionsabnahme]]

## Einordnung

Neu ist die konkrete Übertragung außerhalb der Softwareentwicklung. Der Autor warnt, dass eine Karte für die gesamte Strategie durch veränderte frühe Annahmen veraltet; seine Bevorzugung schneller Prototypen ist eine Heuristik.

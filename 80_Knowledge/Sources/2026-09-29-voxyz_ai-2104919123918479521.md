# Audit-Prompt: Setup gegen den Sonnet-5.5-Leitfaden prüfen

Vox liefert einen Prompt, mit dem Claude Code das eigene Setup gegen Anthropics Leitfaden zu Sonnet 5.5 prüft ([[2026-09-28-claude-building-with-claude-sonnet-5-5-claude-dev-blog]]). Stand 2026-09-29; Aussagen zu Version und Preis stammen von Vox.

## Kernaussagen
- Ab Claude Code 2.1.284 laufen Subagents mit `model: sonnet` auf Sonnet 5.5; Effort-Stufen sind neu kalibriert und nicht von Sonnet 5 übertragbar → [[Modell-Eskalation-von-guenstig-nach-teuer]]
- Leiter: `medium` für klar umrissene Arbeit, `high` für schwerere oder längere, `xhigh`/`max` nur bei gemessenem Gewinn.
- Der Audit sucht Subagents ohne Modell (laufen auf Opus), hart codierte Effort-Stufen und kontraproduktive Altanweisungen („think less“, „do not be lazy“).

## Einordnung
Vox nennt Sonnet „halb so teuer“ wie Opus; das steht nicht im Leitfaden und ist ungeprüft. Der Audit-Prompt ist ein brauchbares Vorgehen, ersetzt aber keine eigene Messung.

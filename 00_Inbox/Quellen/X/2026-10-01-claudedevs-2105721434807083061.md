### 1/7

You can now mod Claude Code:

- Change how it behaves
- Customize the UI
- Swap in your own features

Write one with a few lines of TypeScript, or have Claude build it for you. Mods ship inside plugins, so you install them with /plugin in the CLI or desktop app.

A few examples: https://t.co/qMtzV8AeId

### 2/7

Token Weather adds a forecast of your context window: how full it is, plus a sparkline of your last 12 turns. https://t.co/z2oN4aPkfn

### 3/7

Blast Radius catches risky shell commands like rm -rf, git reset --hard, or a force push before they run. It shows what the command would touch in a side pane. https://t.co/NGGOwRlDfy

### 4/7

Replay Theater records every file edit Claude makes in a turn. Run /replay to step through the diffs one at a time in a docked pane. https://t.co/hHnPYAOaJu

### 5/7

Keep mods to yourself, or submit them to the Claude directory if others might find them useful. Mods run with the same access to your machine as Claude Code itself, so make sure to only install mods from sources you trust.

https://t.co/BwAvIVj8Dv

### 6/7

We're adding pre-built sample mods to the Claude Code Playground repo you can riff off of, if you need some inspiration.

Learn more in our getting started guide: https://t.co/RQgKfEzU0c

### 7/7

We’ve used mods to build features like /diff and AGENTS.md support. We hope you find them as useful (and fun) as we do, and can't wait to see what you build!

https://t.co/0BU3OK2C6p

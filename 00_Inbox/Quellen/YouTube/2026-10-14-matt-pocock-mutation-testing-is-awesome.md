## Transkript

Eine hochwertige Testsuite ist für Agents unerlässlich, aber woher wissen Sie, ob Ihre Testsuite so gut ist, wie sie sein könnte? Nun, eine Möglichkeit, Ihre Testsuite zu verbessern, ist die Durchführung von Mutationstests. Mutationstests funktionieren so, dass sie Ihren Quellcode betrachten und Mutationen daran vornehmen. Hier wurde zum Beispiel dieser JavaScript-String in einen leeren String umgewandelt. Anschließend werden Ihre Tests erneut ausgeführt, um zu prüfen, ob sie fehlschlagen. Jede dieser Mutationen, die Ihre Tests überlebt, ist ein überlebender Mutant. Und das ist ein Mutant, der eliminiert werden muss.

Dies liefert Ihrem Agenten sehr wertvolles Feedback über die Qualität seiner Tests; Sie werden feststellen, dass er danach viel strengere Tests erstellt und Sie wissen, dass jeder dieser Tests tatsächlich einen potenziellen Fehler in Ihrem System aufdeckt. Ich liebe Mutationstests einfach, und ich empfehle sie jedem, der ein wenig besorgt über die Qualität der Tests ist, die sein Agent schreibt. In diesem Beispiel habe ich Stryker.js für TypeScript verwendet, aber es gibt viele weitere Optionen, je nachdem, mit welcher Sprache Sie arbeiten.
